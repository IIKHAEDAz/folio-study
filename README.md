# Folio — เว็บจดโน้ตและจัดการงานเรียน

## ไฟล์ในชุด
- index.html: เว็บครบในไฟล์เดียว รวม CSS, JavaScript และฟอนต์ไทย
- README.md: วิธีใช้งานและเผยแพร่

## ทดลองใช้
แตก ZIP แล้วเปิด index.html ในเบราว์เซอร์

## อัปโหลดขึ้น GitHub
1. เข้าสู่ระบบ GitHub แล้วกด + มุมขวาบน → New repository
2. ตั้งชื่อ เช่น folio-study และเลือก Public แล้วกด Create repository
3. กด uploading an existing file หรือ Add file → Upload files
4. ลากไฟล์ index.html และ README.md ที่แตก ZIP แล้วลงไป (อย่าอัปโหลดไฟล์ ZIP)
5. กด Commit changes

## เปิดเว็บด้วย GitHub Pages
1. ใน Repository ไปที่ Settings → Pages
2. ใน Build and deployment เลือก Source: Deploy from a branch
3. เลือก Branch: main และโฟลเดอร์ / (root) แล้วกด Save
4. รอให้ GitHub เผยแพร่ แล้วใช้ลิงก์เว็บที่แสดงในหน้า Pages

ลิงก์ GitHub /feed เป็นหน้าฟีด ไม่ใช่พื้นที่อัปโหลดไฟล์ของ Repository

## ข้อมูลที่บันทึก
เว็บบันทึกโน้ต การบ้าน โปรเจกต์ และตารางเรียนในเบราว์เซอร์ของแต่ละเครื่อง ยังไม่ซิงก์ข้ามอุปกรณ์ เมื่อย้ายจากลิงก์เดิมมาที่ GitHub Pages ให้ส่งออกข้อมูลในหน้า ตั้งค่า & สำรอง ของเว็บเดิม แล้วนำเข้าไฟล์บนเว็บใหม่
